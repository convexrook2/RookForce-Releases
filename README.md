# RookForce Releases

Public Windows installer releases for **RookForce**.

The source code is maintained in a private repository. This public repository contains download metadata only; installers and their SHA-256 checksums are published through [GitHub Releases](https://github.com/convexrook2/RookForce-Releases/releases).

## Download

Open the [latest release](https://github.com/convexrook2/RookForce-Releases/releases/latest) and download:

- `RookForce-Setup-<version>.exe`
- `SHA256SUMS.txt`

The installer and application are currently unsigned, so Windows may show an unrecognized-publisher warning. Verify the installer against `SHA256SUMS.txt` before running it.
